# Knight Arena — Greenfoot Prototype

Greenfoot Java project from `KnightArena_Greenfoot_Prototype(3).zip`.

Source code and Greenfoot project configuration are in [KnightArena_Prototype](KnightArena_Prototype).

**Important:** The original ZIP also contains PNG artwork and WAV sound effects. Those binary files have not yet been uploaded through the GitHub connector. The repository is currently **source-only** and will not run correctly without the `KnightArena_Prototype/images/` and `KnightArena_Prototype/sounds/` directories from the original ZIP.

To run the full game right now, extract the original ZIP and open `KnightArena_Prototype/project.greenfoot` in Greenfoot. See the project's README.txt for controls and gameplay.
